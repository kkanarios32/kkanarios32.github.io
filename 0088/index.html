Expectation Maximization [0088]

  • July 1, 2025
  • Kellen Kanarios
  • 6 min read

This is the follow up to the previous note on the ELBO. Mainly, here we aim to show how we can use the ELBO to find \(\theta ^*\) i.e. \[ \begin {align*} \theta ^* &= \arg \max \mathbb {E}_{x \sim \mathcal {D}} \log p(x; \theta ) \\ &= \arg \max \mathbb {E}_{x \sim \mathcal {D}} \log \int p(x, z; \theta ) \mathrm {d}z .\end {align*} \] Notably, ELBO gives us the lower bound \[\log p(x; \theta ) \geq \mathbb {E}_{z \sim q}\left [\log \frac {p(x, Z; \theta )}{q(z)}\right ] \eqqcolon \mathsf {ELBO}(x, q, \theta )\] for a fixed theta and \(q\). Therefore, for each \(\theta \), we want to find some \(q\), such that \[\mathsf {ELBO}(x, q, \theta ) = \log p(x, \theta )\] With this, we can easily perform gradient ascent \[\theta _{t + 1} \gets \theta _t + \nabla _{\theta } \mathsf {ELBO}(x, q, \theta _t),\] to maximize the log-likelihood \(\log p(x; \theta )\).

Remark. Note that the gradient is with respect to \(\theta \), where \(\theta \) is just the third argument to \(\mathsf {ELBO}\) as defined above. Notably, \(\theta _t\) will show up elsewhere later but will NOT be backpropagated through.

1. Expectation

  • July 1, 2025
  • Kellen Kanarios

The above motivates the expectation step of the EM algorithm. Namely how can we compute the lower bound expectation for the best possible \(q\).

Recall (or review) from the discussion on ELBO that \(q(z) = p(z | x; \theta )\) maximizes the ELBO for a given \(x\) and \(\theta \). Therefore, we actually want to learn \(q_{\phi }(z, x, \theta ) \approx p(z | x; \theta )\). To do so, we can simply maximize the ELBO (duh). Formally, \[\phi _{t+1} = \argmax _{\phi } \mathbb {E}_{x \sim \mathcal {D}, z \sim q}\left [\log \frac {p(x, Z; \theta _t)}{q_{\phi }(Z, x, \theta _t)}\right ]\]

Question. Now this is all cool theoretically but how TF do we actually maximize this thing?
Answer. It is highly dependent on the parametrization of \(p\) and \(q\).
Example.

We define the problem as

  1. \(p(z) \sim N(0, 1)\)
  2. \(p(x | z; \theta ) \sim N(\mu _{\theta }(z), \sigma _{\theta }(z))\)
  3. \(q_{\phi }(z | x, \theta ) \sim N(\mu _{\phi }(x), \sigma _\phi (x))\)
where \(\mu _{\{\phi , \theta \}}, \sigma _{\{\phi , \theta \}}\) are parametrized neural networks. Then we can rewrite the ELBO as (ignoring constants) \[ \begin {align*} \mathsf {ELBO}(x, q, \theta ) &= \mathbb {E}_{x \sim \mathcal {D}, z \sim q(\cdot \mid x, \theta )} \left [\log p(Z) - \log \frac {p(x \mid Z; \theta )}{q_{\phi }(Z, x, \theta )}\right ] \\ &= \mathbb {E}_{x \sim \mathcal {D}, z \sim q(\cdot \mid x, \theta )} \left [-\frac {Z^2}{2} - \frac {\sigma _{\phi }(x)^2}{\sigma _{\theta }(z)^2}\big ((Z - \mu _{\theta }(Z))^2 - (Z - \mu _{\phi }(x))^2\big )\right ] .\end {align*} \]

Problem. We need to sample realization \(z \sim q_{\phi }(\cdot |x, \theta )\). So isn't our realization \(z\) a function of \(\phi \). How would we optimize this?
Answer. The reparametrization trick!!

Now for a given sample \(x_i \sim \mathcal {D}\), we can get a sample \(z_i(\phi ) \sim q(\cdot \mid x_i, \theta )\) that is differentiable with respect to \(\phi \). Using this, we can get the stochastic gradient estimate \[\nabla _q \widetilde {\mathsf {ELBO}}(x, q, \theta ) = \nabla _{\phi } \left [\frac {z_i(\phi )^2}{2} - \frac {\sigma _{\phi }(x)^2}{\sigma _{\theta }(z)^2}\big ((z_i(\phi ) - \mu _{\theta }(z_i(\phi )))^2 - (z_i(\phi ) - \mu _{\phi }(x))^2\big )\right ]\]

Algorithm. input \(\theta _t\)
  1. Sample \(x_i\) from dataset \(\mathcal {D}\)
  2. Sample \(z_i(\phi ) \sim q_{\phi }(\cdot \mid x_i, \theta _t)\) via trick.
  3. Compute \(\nabla _q \widetilde {\mathsf {ELBO}}\)
  4. Update via SGD

2. Maximization

  • July 1, 2025
  • Kellen Kanarios

Finally, we have reached the maximization step. This step is fairly straightforward after all the progress we have made. Once we have a tight lower bound i.e. \(q(z) \approx p(z \mid x; \theta )\) then we simply fix \(q\) and maximize the ELBO for \(\theta \) i.e. in the above example and algorithm we instead compute \[\nabla _\theta \widetilde {\mathsf {ELBO}}(x, q, \theta ) = \nabla _{\theta } \left [\frac {z_i(\phi )^2}{2} - \frac {\sigma _{\phi }(x)^2}{\sigma _{\theta }(z)^2}\big ((z_i(\phi ) - \mu _{\theta }(z_i(\phi )))^2 - (z_i(\phi ) - \mu _{\phi }(x))^2\big )\right ]\] Alternating between these steps yields the expectation-maximization algorithm the ML oldheads mythologize.

    Unlike in DDO, where they do exact posterior inference, here we do variational inference. Namely, they directly try to model the posterior via the neural network \(\eta _{\theta }(z_{t} \mid z_{t - 1}, b_{t}, x_{1:T},a_{1:T})\). This has a few consequences:

    \[\begin {align*} \mathcal {L}_{\text {ELBO}}(\theta ) \approx \sum _{t=1}^{T} \log &p_{\theta }(\mathbf {a}_{t} \mid \mathbf {s}_{t}) + D_{\text {KL}}(q_{\theta }(m_{t} \mid \mathbf {x}_{1:t}) \parallel p_{\theta }(m_{t} \mid \mathbf {s}_{t})) \\ &+ D_{\text {KL}}(q_{\theta }(z_{t} \mid m_{t}, \mathbf {x}_{1:T}, \mathbf {a}_{1:T}) \parallel p(z_{t})) + D_{\text {KL}}(q_{\theta }(s_{t} \mid z_{t}, \mathbf {x}_{t}) \parallel p_{\theta }(s_{t} \mid s_{t-1}, m_{t-1})) .\end {align*}\]

    The setup for Multi-Level Discovery of Deep Options:

    • We have a meta-controller that outputs the skill \(z\) given the state \(s\) i.e. \(z_t \sim \eta (\cdot \mid s_t)\)
    • We have the skill, which is a skill-conditioned policy \(a_t \sim \pi (\cdot \mid s_t, z_t)\)
    • We have the termination function \(\psi (\cdot \mid s_t, z_{t - 1})\), which is per skill and evaluates the previous skill \(z_{t - 1}\) at the new state \(s_t\), such that \(b_t \sim \mathrm {Ber}\big (\psi (s_t, z_{t - 1})\big ) \in \{0, 1\} \)
      • For \(b_t = 1\), we resample a new skill \(z_t \sim \eta (\cdot \mid s_t)\)
      • Otherwise, \(z_{t} = z_{t - 1}\)

    Assuming there is a true underlying latent history \(\xi = \{b_{0}, z_{0}, b_{1}, z_{1}, \ldots \} \) and the observable history \(\mathcal {H} = \{s_{0}, a_{0}, s_{1}, a_{1}, \ldots \} \), the likelihood according to the above generative model is given by

    \[\mathbb {P}(\mathcal {H}, \xi ) = p(s_{0})\delta _{\{b_{0} = 1\}}\eta (z_{0} \mid s_{0}) \prod _{t=1}^{T - 1} \mathbb {P}(b_t, z_t \mid z_{t - 1}, s_t) \prod _{t = 0}^{T - 1} \pi (a_t \mid s_t, z_t) p(s_{t+1} \mid s_t, a_t)\]

    Furthermore, according to our model, we have that

    \[ \begin {align*} \mathbb {P}(b_t = 0, z_t \mid z_{t - 1}, s_t) &= (1 - \psi (s_t, z_{t - 1})) \cdot \delta _{\{z_{t} = z_{t - 1}\}} \\ \mathbb {P}(b_t = 1, z_t \mid z_{t - 1}, s_t) &= \psi (s_t, z_{t - 1}) \cdot \eta (z_t \mid s_t) .\end {align*} \]

    Up to this point, we have assumed this is the ground truth model and we are given each of the components. Instead we want to learn these components. To do so, we introduce our set of parameters \(\mathbf {\theta } \), such that each component is parametrized by a subset of \(\mathbf {\theta } \) i.e. \(\eta _{\theta }, \pi _{\theta }, \psi _{\theta }\).

    Goal. We want to learn some \(\theta \) that maximized the likelihood of the observable data.

    To do so, first consider the log-likelihood of our new parametrized model

    \[ \begin {align*} \log \mathbb {P}_{\theta }(\mathcal {H}, \xi ) &= \log \left [p(s_{0})\delta _{\{b_{0} = 1\}}\eta _{\theta }(z_{0} \mid s_{0}) \prod _{t=1}^{T - 1} \mathbb {P}_{\theta }(b_t, z_t \mid z_{t - 1}, s_t) \prod _{t = 0}^{T - 1} \pi _{\theta }(a_t \mid s_t, z_t) p(s_{t+1} \mid s_t, a_t)\right ] \\ &= \log p(s_{0})\delta _{\{b_{0} = 1\}} + \log \left [\eta _{\theta }(z_{0} \mid s_{0}) \prod _{t=1}^{T - 1} \mathbb {P}_{\theta }(b_t, z_t \mid z_{t - 1}, s_t) \prod _{t = 0}^{T - 1} \pi _{\theta }(a_t \mid s_t, z_t) \right ] + \sum _{t=0}^{T-1} \log \left [p(s_{t+1} \mid s_t, a_t)\right ] \\ &= \underbrace {\log p(s_{0})\delta _{\{b_{0} = 1\}} + \sum _{t=0}^{T-1} \log \left [p(s_{t+1} \mid s_t, a_t)\right ]}_{\text {independent of } \theta } + \log \left [\eta _{\theta }(z_{0} \mid s_{0}) \prod _{t=1}^{T - 1} \mathbb {P}_{\theta }(b_t, z_t \mid z_{t - 1}, s_t) \prod _{t = 0}^{T - 1} \pi _{\theta }(a_t \mid s_t, z_t)\right ] .\end {align*} \]

    Since we are only concerned with learning \(\theta \), we can disregard the \(\theta \) independent terms leaving

    \[\begin {align*} \nabla _{\theta } \log \mathbb {P}_{\theta }(\mathcal {H}, \xi ) &= \nabla _{\theta } \left [ \log \left [\eta _{\theta }(z_{0} \mid s_{0}) \prod _{t=1}^{T - 1} \mathbb {P}_{\theta }(b_t, z_t \mid z_{t - 1}, s_t) \prod _{t = 0}^{T - 1} \pi _{\theta }(a_t \mid s_t, z_t)\right ] \right ]\\ &= \nabla _{\theta } \log \left [\eta _{\theta }(z_{0} \mid s_{0})\right ] + \sum _{t=1}^{T - 1} \nabla _{\theta } \log \left [\mathbb {P}_{\theta }(b_t, z_t \mid z_{t - 1}, s_t)\right ] + \sum _{t = 0}^{T - 1} \nabla _{\theta } \log \left [\pi _{\theta }(a_t \mid s_t, z_t)\right ]. \end {align*}\]
    Problem. This requires samples \((\mathcal {H}, \xi ) \sim P_{\theta }(\mathcal {H}, \xi )\), but we only have samples \(\mathcal {H} \sim P_{\theta }(\mathcal {H})\)!!!
    Solution.We can use the trick from Expectation Maximization. Referred to in the paper as the expectation gradient trick. Namely, \[\nabla _{\theta } \log P_{\theta }(\mathcal {H}) = \mathbb {E}_{\xi \sim P_{\theta }(\xi \mid \mathcal {H})} \left [ \nabla _{\theta } \log P_{\theta }(\mathcal {H}, \xi ) \right ]\]

    Now it remains to compute the expectation from \(P_{\theta }(\xi \mid \mathcal {H})\)

    Remark. Note that \(P_{\theta }(\xi \mid \mathcal {H})\) is a distribution over \((K, \{0,1\})^{T} \) i.e. over each \((z_t, b_t)\). To efficiently compute, we need to use Forward-backward algorithm.

    We have that

    \[\nabla _{\theta } L[\theta ; \xi ] = \sum _{h \in \mathcal {H}} \left ( \sum _{t=0}^{T-1} \left ( v_t(z) \nabla _{\theta } \log \eta (z|s_t) + u_t(z) \nabla _{\theta } \log \pi _h(a_t|s_t) \right ) + \sum _{t=0}^{T-2} \left ( (u_t(z) - w_t(z)) \nabla _{\theta } \log \psi _h(s_{t+1}) + w_t(z) \nabla _{\theta } \log (1 - \psi _h(s_{t+1})) \right ) \right ).\]

    Following the Forward-backward algorithm, we can get the posterior for the latent i.e. \(\mathbb {P}((z_{t}, b_{t}) \mid \mathcal {H})\). We have the corresponding forward and backward components

    \[\begin {align*} \phi _t(z, b) &= \mathbb {P}(s_{0}, a_{0}, \ldots , s_{t}, z_{t} = z, b_{t} = b) \\ \beta _t(z, b) &= \mathbb {P}(s_{t + 1}, a_{t + 1}, \ldots , s_{T} \mid z_{t} = z, b_{t} = b), .\end {align*}\]

    which can then be written as

    \[\begin {align*} \phi _t(z, b) &= \mathbb {P}(s_t, a_t \mid z, b) \sum _{(z', b')} \phi _{t - 1}(z', b') \mathbb {P}(z, b \mid z', b') \\ \beta _t(z, b) &= \sum _{(z', b')} \beta _{t + 1}(z', b') \mathbb {P}(s_{t + 1}, a_{t + 1} \mid z', b') \mathbb {P}(z', b' \mid z, b) .\end {align*}\]

    Forward pass. For the forward pass, we have the initial condition

    \[\phi _0(z, b) = p_{0}(s_{0}) \delta _{\{b = 1\}} \eta (z \mid s_{0})\]

    Here \((z', b')\) ranges over the possible values of \((z_{t - 1}, b_{t - 1})\). It is sufficient to expand the remaining two terms in terms of our generative model as defined above. First, note that \((z_{t}, b_{t})\) are independent of \(b_{t - 1}\). Therefore, we can drop the \(b_{t - 1}\) term and are left with the following two cases:

    \[\begin {align*} \mathbb {P}_{\theta }(z, b = 0 \mid z') &= \delta _{\{z = z'\}} (1 - \psi _{\theta }(s_{t}, z')) \\ \mathbb {P}_{\theta }(z, b = 1 \mid z') &= \eta _{\theta }(z \mid s_{t}) \psi _{\theta }(s_{t}, z') .\end {align*}\]

    Plugging this in, we now have

    \[\begin {align*} \phi _t(z, b) = \mathbb {P}_{\theta }(s_t, a_t \mid z, b) \sum _{(z', b')} \phi _{t - 1}(z', b') \Big (&\eta _{\theta }(z \mid s_{t}) \psi _{\theta }(s_{t}, z') \\ &+ \delta _{\{z = z'\}} (1 - \psi _{\theta }(s_{t}, z'))\Big ) .\end {align*}\]

    It remains to find \(\mathbb {P}_{\theta }(s_t, a_t \mid z, b)\). Once again, given \(z_t\) we no longer care about \(b_t\). Therefore, this becomes

    \[\begin {align*} \mathbb {P}_{\theta }(s_t, a_t \mid z) &= \pi _{\theta }(a_t \mid s_t, z) p(s_t \mid s_{t - 1}, a_{t - 1}) .\end {align*}\]

    This gives us our final expression

    \[\begin {align*} \phi _t(z, b) = &\pi _{\theta }(a_t \mid s_t, z) p(s_t \mid s_{t - 1}, a_{t - 1}) \\ &\times \sum _{(z', b')} \phi _{t - 1}(z', b') \Big (\eta _{\theta }(z \mid s_{t}) \psi _{\theta }(s_{t}, z') + \delta _{\{z = z'\}} (1 - \psi _{\theta }(s_{t}, z'))\Big ) .\end {align*}\]
    Remark. We have abused notation here, allowing \(\mathbb {P}(s_t, a_t \mid z_t, b_t)\) to depend on \(s_{t - 1}, a_{t - 1}\), etc. This is to align with the notation from Forward-backward algorithm. It makes no difference in practice as long as the backward dependence is finite / bounded. However, in practice you would want the history dependence to be small and here it is only one-step.

    Backward pass. For the backward pass, we define the end term as

    Here \((z', b')\) ranges over the possible values of \((z_{t + 1}, b_{t + 1})\). The other terms are analagous i.e.

    Normalizing Flows [B9J9]

    Brief notes on Variational Inference with Normalizing Flows to motivate flow matching.

    Goal. We are concerned with the problem of density estimation. Given a dataset \(\mathcal {X}\), consisting of samples \(\mathbf {x}_i \sim p(\mathbf {x})\), we want to learn \(p(\mathbf {x})\).

    One popular way to do this is via variational inference. As a brief recap, in variational inference, we assume that there is actually a joint distribution \(p(\mathbf {x}, \mathbf {z})\), where \(\mathbf {z}\) is a latent variable. We then find \(p(\mathbf {x})\) by maximizing the log-likelihood \(\log \int p(\mathbf {x} \mid \mathbf {z}) \mathrm {d}\mathbf {z}\)

    For an example of this, see my post on expectation maximization. In that post, we utilize the ELBO to learn a latent variable model \(q_{\phi }(\mathbf {z} | \mathbf {x})\). As discussed in my post on ELBO, in order to learn \(p(\mathbf {x})\), we must have that \(p(\mathbf {z} | \mathbf {x})\) is in the family \(q_{\phi }\). However, \(q_ {\phi }\) is usually a Gaussian parametrized by \(\phi \), so that we can easily learn \(\phi \). In this case, it is very unlikely that \(p(\mathbf {z} \mid x)\) lies in the family of \(q_{\phi }\) and therefore we have no hope of learning the true \(p(\mathbf {x})\).

    Evidence Lower Bound [0082]

    • June 30, 2025
    • Kellen Kanarios
    • 5 min read

    Setup. We are given a joint distribution \(p(X, Z; \theta )\), where \(X\) and \(Z\) are random variables with their joint parametrized by \(\theta \). We are also given a dataset \(\mathcal {D}\) containing realizations of only \(X\) i.e. \(Z\) is a latent random variable.

    Goal. We want to learn \(p(x; \theta )\).

    However, \[p(x; \theta ) = \int p(x, z; \theta ) \mathrm {d}z = \int p(x | z; \theta )p(z) \mathrm {d}z,\] which is computationally intractable for most continuous \(Z\).

    Question. Can we update \(\theta \) for a given realization of \(x\) and \(z\)?
    Answer.Yes!!!

    Motivation. Suppose we had some \(q(z)\) that we could sample realizations of \(Z\) from. Then we want to find some reasonable \(\ell _{\theta }\), such that \[\theta ^* \approx \arg \max _{\theta } \mathbb {E}_{x, \sim p(x; \theta ^*), z \sim q(z)}[\ell _{\theta }(X, Z)]\]

    Remark. \(q(z)\) can potentially (and will) depend on the sample \(x_i\). This is OK because we are given \(x_i\)'s, which we can then just pass to \(q\) to get the corresponding \(z_i\).
    Why is this the case? Because then (for well-behaved \(\ell _{\theta }\)) \[\theta _{t + 1} = \theta _{t} - \alpha \nabla _{\theta _{t}}\ell _{\theta _{t}}(x_i, z_i) \to \theta ^*\] i.e. SGD is a reasonable thing to do, where the gradient is for a single sample of \(x_i\) and \(z_i\) which we have readily available from our dataset \(\mathcal {D}\) and our distribution \(q\) that we can sample from. This idea comes up a lot in optimization, such as the \(\log \) trick in the original policy gradient.

    Similar to the \(\log \) trick, the Evidence Lower Bound (ELBO) comes from a simple multiply and divide trick. Namely, \[\begin {align*} \log p(x; \theta ) &= \log \int p(x, z; \theta ) \mathrm {d}z \\ &= \log \int p(x, z; \theta ) \frac {q(z)}{q(z)} \mathrm {d}z \\ &= \log \mathbb {E}_{z \sim q(z)} \frac {p(x, Z; \theta )}{q(z)} \\ &\geq \mathbb {E}_{z \sim q(z)} \log \frac {p(x, Z; \theta )}{q(z)} .\end {align*}\] The last inequality follows directly from Jensen's Inequality. However, note that this is only a lower bound and therefore not exactly what we want. For example, if we were to pick \(q \sim N(0, 1)\) and then optimize the ELBO for \(\theta \) we would not necessarily find a good \(\theta \) for the likelihood \(\log p(x; \theta )\). Luckily, we can actually get the difference \(\log p(x; \theta ) - \)ELBO in closed form! Namely, \[\begin {align*} \log p(x; \theta ) - \mathrm {ELBO} &= \log p(x; \theta ) - \mathbb {E}_{z \sim q(z)} \log \frac {p(x, Z; \theta )}{q(z)} \\ &= \int \left (\log p(x; \theta ) - \log \frac {p(x, z; \theta )}{q(z)}\right )q(z) \\ &= \int \left (\log \frac {p(x; \theta )q(z)}{p(x, z; \theta )}\right )q(z) \\ &= \int \left (\log \frac {p(x; \theta )q(z)}{p(z | x; \theta )p(x; \theta )}\right )q(z) \\ &= \int \left (\log \frac {q(z)}{p(z | x; \theta )}\right )q(z) \\ &= \mathrm {KL}\big (q(z) \mid \mid p(z | x; \theta )\big ) .\end {align*}\] Thus, to tighten the lower bound we can optimize \(q_{\phi }(z)\) to try to match \(p(z | x; \theta )\). As a sanity check, lets make sure these match when \(q(z) = p(z \mid x; \theta )\). \[\begin {align*} \mathbb {E}_{z \sim q(z)} \log \frac {p(x, Z; \theta )}{q(z)} &= \int \log \frac {p(x, z; \theta )}{q(z)}\mathrm {d}z \\ &= \int \log \frac {p(x; \theta )p(z \mid x; \theta )}{p(z \mid x; \theta )}\mathrm {d}z \\ &= \int \log p(x; \theta )\mathrm {d}z \\ &= \log (x; \theta ) .\end {align*}\] You may be wondering how we use this algorithmically to find \(\theta ^*\)? This will be the main idea of expectation maximization. Feel free to check it out!

      Remark. \(q(z)\) can potentially (and will) depend on the sample \(x_i\). This is OK because we are given \(x_i\)'s, which we can then just pass to \(q\) to get the corresponding \(z_i\).
      Why is this the case? Because then (for well-behaved \(\ell _{\theta }\)) \[\theta _{t + 1} = \theta _{t} - \alpha \nabla _{\theta _{t}}\ell _{\theta _{t}}(x_i, z_i) \to \theta ^*\] i.e. SGD is a reasonable thing to do, where the gradient is for a single sample of \(x_i\) and \(z_i\) which we have readily available from our dataset \(\mathcal {D}\) and our distribution \(q\) that we can sample from. This idea comes up a lot in optimization, such as the \(\log \) trick in the original policy gradient.

      Similar to the \(\log \) trick, the Evidence Lower Bound (ELBO) comes from a simple multiply and divide trick. Namely, \[\begin {align*} \log p(x; \theta ) &= \log \int p(x, z; \theta ) \mathrm {d}z \\ &= \log \int p(x, z; \theta ) \frac {q(z)}{q(z)} \mathrm {d}z \\ &= \log \mathbb {E}_{z \sim q(z)} \frac {p(x, Z; \theta )}{q(z)} \\ &\geq \mathbb {E}_{z \sim q(z)} \log \frac {p(x, Z; \theta )}{q(z)} .\end {align*}\] The last inequality follows directly from Jensen's Inequality. However, note that this is only a lower bound and therefore not exactly what we want. For example, if we were to pick \(q \sim N(0, 1)\) and then optimize the ELBO for \(\theta \) we would not necessarily find a good \(\theta \) for the likelihood \(\log p(x; \theta )\). Luckily, we can actually get the difference \(\log p(x; \theta ) - \)ELBO in closed form! Namely, \[\begin {align*} \log p(x; \theta ) - \mathrm {ELBO} &= \log p(x; \theta ) - \mathbb {E}_{z \sim q(z)} \log \frac {p(x, Z; \theta )}{q(z)} \\ &= \int \left (\log p(x; \theta ) - \log \frac {p(x, z; \theta )}{q(z)}\right )q(z) \\ &= \int \left (\log \frac {p(x; \theta )q(z)}{p(x, z; \theta )}\right )q(z) \\ &= \int \left (\log \frac {p(x; \theta )q(z)}{p(z | x; \theta )p(x; \theta )}\right )q(z) \\ &= \int \left (\log \frac {q(z)}{p(z | x; \theta )}\right )q(z) \\ &= \mathrm {KL}\big (q(z) \mid \mid p(z | x; \theta )\big ) .\end {align*}\] Thus, to tighten the lower bound we can optimize \(q_{\phi }(z)\) to try to match \(p(z | x; \theta )\). As a sanity check, lets make sure these match when \(q(z) = p(z \mid x; \theta )\). \[\begin {align*} \mathbb {E}_{z \sim q(z)} \log \frac {p(x, Z; \theta )}{q(z)} &= \int \log \frac {p(x, z; \theta )}{q(z)}\mathrm {d}z \\ &= \int \log \frac {p(x; \theta )p(z \mid x; \theta )}{p(z \mid x; \theta )}\mathrm {d}z \\ &= \int \log p(x; \theta )\mathrm {d}z \\ &= \log (x; \theta ) .\end {align*}\] You may be wondering how we use this algorithmically to find \(\theta ^*\)? This will be the main idea of expectation maximization. Feel free to check it out!
